# Harlequin Masque — Horus Heresy 1st Edition BattleScribe Repository

A fan-made Horus Heresy 1.0 Harlequin army catalogue derived from the supplied **Harlequins: Codex (2015) / Death Masque** BattleScribe catalogue and expanded with the Playwright Masque units and armoury.

## Repository files

This repository intentionally follows the same four-file layout as the Rangdan Confederacy repository:

1. `Harlequin_Masque_HH1.catz` — BattleScribe catalogue archive.
2. `index.bsi` — BattleScribe repository index archive.
3. `index.xml` — plain-text repository index.
4. `README.md` — documentation.

## Horus Heresy force organisation

The catalogue uses an HH1-style Crusade Detachment:

- HQ: 1–3
- Troops: 2–6
- Elites: 0–4
- Fast Attack: 0–3
- Heavy Support: 0–3
- Lords of War: 0–1 and no more than 25% of roster points
- Dedicated Transport: available separately

The post-Heresy Ynnari named characters are not presented as army choices.

## Battle order cleanup

Veil Mimes use the revised **Silent Performance** wording. Line of sight is checked at the start of the Assault phase and then affects Overwatch when the charge is declared. It does not grant permission to charge in a turn when charging would normally be prohibited.

## Characteristic-changing upgrades

The Playwright's Skyweaver Jetbike is implemented with BattleScribe characteristic modifiers as well as descriptive rules:
- Toughness +1
- Wounds +1

The roster therefore has data-level stat changes rather than relying solely on prose.

## Installation

Add the repository's `index.bsi` or `index.xml` as a BattleScribe data repository, then update data and select **(HH V1) Harlequin Masque Army List (Fanmade)** under the Horus Heresy 1st Edition game system.

## Notes

This is fan-made material intended for Horus Heresy 1st Edition / 7th-edition-derived play. Existing 2015 Harlequin material is used as the mechanical base, while the Playwright Masque additions are custom rules.
